# 平衡

## 伤害公式

```
伤害 = (基础 + 固定) × (1 + Σ加成%) × Π独立乘区 × 暴击 × 连锁倍率 × 目标易伤
```

- **加成%**（相加）：大部分遗物、天赋、2/4 层羁绊。前中期够用，后期收益被血量成长吃掉。
- **独立乘区**（各自相乘，修正项键名以 `x` 开头，界面显示成「×1.2」）：
  - 词缀「致命」×1.5
  - 钻品质 ×1.25
  - 6 层羁绊：刃 / 火 / 冰 / 电 ×1.3，毒 ×1.35
  - 传说遗物和玻璃大炮：守夜人之誓 ×1.2、深渊碎片 ×1.35、龙心（火）×1.3、千机匣（机）×1.25、淬毒之刃（刃）×1.3、残破的军旗 ×1.12、全城的灯谱 ×1.12、玻璃大炮 ×1.25
  - **C 位** ×1.25：每局一张主力，第 3、5、7 夜之前的跃迁事件（按人物不同）或「操练」事件来定；璃的星辉每层再 ×1.1
  - **站位**：占正中、在两端、两边都是辅助……（卡上标【站位】）
- **连锁倍率**：被回响、齐鸣、遗物带出来的出手，每深一层 +10%，最多 8 层（×1.8）。回响每张卡每秒最多被带动 2 次。

## 爽感机制（`src/sim/combo.ts`）

- **元素反应**：这一下的元素碰上敌人身上已有的状态。同一个敌人 0.5 秒内只反应一次（`TUNE.rxCd`），追加伤害按这一下实际打掉的血算，不再吃易伤和护甲。
  - 融化：火打冻住的 → +60%，解冻
  - 碎冰：非火暴击冻住的 → +80%，周围 40%，解冻
  - 超载：电打烧着的 → 周围 50% 并点着
  - 毒爆：火打中毒的 → 30% 范围伤害，毒传给周围（只拉平到源头的一半，不叠加）
  - 超导：电打减速或冻住的 → 易伤 20% 3 秒
- **流派连招**：同元素 3 秒内出手 4 次（至少两张卡）放一次大招，每个元素冷却 14 秒。伤害以窗口内最高的卡面伤害为基准：千刃 6 刀各 70%，燎原 30% 加灼烧，冰封 40% 加冻结 0.8 秒，雷暴 5 道各 60%，疫潮染毒，全速给【机】卡充能加速。
- **连杀分级**：连杀 10 / 25 / 50 / 100 时全队加速 0.6 / 1 / 1.5 / 2 秒。
- **联动**：两种元素各 2 张时额外生效一条（`SYN2`，15 组）；冷热、雷火、毒火、寒雷、寒锋各加强一种反应。

旋钮：`rx`、`rxCd`、`streakWin`、`streakN`、`streakCd`、`frenzy`、`syn2`（后两个填 0 可关掉，用来测各自贡献）。

## 敌情（`src/data/threats.ts`）

- 每夜剧情点名的敌人固定（第 2 夜炸弹鼠、第 4 夜暗影骑士、第 6 夜攻城塔……），其余出怪从 8 套敌情里抽 1~3 套：蜂群、空袭、重甲、亡灵、冲锋、雾魂、巫祝、火药。第 1 夜全固定。
- 四夜一段，段内敌情不变（构筑是长期的）：第 2~5、6~9 夜各一段，普通 9 夜只遇到两套；完整线再加 10~13、14~15，无尽接着四夜一段。每段抽 3 套，每夜按空位用前 1~3 套。
- 抽取只看本局种子和段号，不动 `rng`；主力不和上一段重样。备战页写今晚敌情，段末那夜（第 5、9、13 夜）再预告下一段。
- 组数按被换掉那包折算：强度比和数量比取几何平均，再除以该套的 `pw`；只数最多比原来多四成（手机性能）。
- 调 `pw`：`NIGHTS=7,8 N=10 npx vitest run -c vitest.balance.config.ts tests/balance/threats.balance.ts --reporter=verbose`，看各套守住率是否接近。

## 规则遗物（`rule: 1`）

第 2、6 夜守住后（第 3、7 夜备战开头）白给三选一，不占三站；不进普通遗物池。对路的（棋盘用得上）权重 ×3。

| 遗物 | 效果 | 接哪套机制 |
| --- | --- | --- |
| 共振叉 | 反应后，打出反应那张卡的邻居充能 20% | 反应 → 充能 |
| 二重唱 | 连招放出时，窗口里另一种元素也放一次（60%） | 连招 × 两元素 |
| 窑心 | 火命中 50% 冻 0.5 秒；融化 +150%，不解冻 | 火 → 冻 → 融化 |
| 试剂瓶 | 每次反应，所有连招冷却 -0.5 秒 | 反应 → 连招 |
| 环城图 | 两端的卡互为相邻 | 相邻、站位 |
| 狂潮号角 | 连杀 25/50/100 时放一次主元素大招（60%） | 连杀 → 连招 |
| 节拍器 | 连招要 6 次出手，冷却 8 秒 | 连招节奏 |
| 连环扣 | 被带动出手的输出卡直接放本元素大招（每 4 秒最多一次） | 连锁 → 连招 |

连招有 14 秒冷却，一场能放几次大招是冷却卡住的；「更容易凑满」的效果没用，所以这几件都绕开或缩短冷却。
第 7 夜各流派平均守住率（不带 53%）：每件 +1~6 点，没有一家独大。窑心对火流派只有 0~8 点，偏弱。
测：`NIGHTS=7 N=5 [ARCH=fire,ice] [ONLY=kiln] npx vitest run -c vitest.balance.config.ts tests/balance/rules.balance.ts --reporter=verbose`

## 风向与外乡卡（`src/game/loot.ts`）

- 风向：开局从这个人物买得到至少 4 张的元素里挑一个。该元素的卡权重 ×2，对应专卖店权重 ×2，第一次挑遗物保底一件顺风的（加该元素伤害 / 攻速，或火的灼烧、冰的减速、电的弹跳；毒没有，不保底）。
- 外乡卡：别的人物的专属卡，那个人物解锁了才会来，总共约占抽卡的一成，价格 +2。标了 `local` 的不卖（誓剑、八音盒，剧情要用）。

## 怪物成长

- 普通敌人血量第 1~7 夜每夜 ×1.34，第 6 夜起每夜再 ×1.18；第 8、9 夜按第 7 夜的倍数单独定（×1.25、×1.65），多出来的一夜让玩家多一轮备战，怪不必再翻一倍。
- 第 9 夜以后（完整线、无尽）普通敌人每夜 ×1.15，首领每夜 ×1.17；隐藏首领按早 3 夜的倍率算（它会不停叫小怪挡在前面）。
- 每夜敌人数量随夜数涨，第 11 夜封顶（再多手机上跑不动）。
- 首领血量 ×1.6；第 9 夜首领五个轮换（深渊之眼、深渊母巢、哑钟、雾母、攻城王）。
- 选目标时精英和首领「往前算」12% 路程：不再躲在小怪后面一路走到墙下。
- 系数：`TUNE.hpGrowth`、`lateHp`、`hp8`、`hp9`、`afterHp`、`bossHp`、`bossAfter`、`hiddenEase`。

## 主要调整

- 闪电弹跳：第一跳 60%，之后每跳 ×0.8；弹跳次数叠得再多，总收益也有上限。
- 雷王杖：伤害 10→7，冷却 1.4→1.6，弹跳 6→4；学徒雷杖升级要 150 次弹跳（原 100）。
- 冰、毒、萤的卡整体加强（冰卡伤害约 +25%~50%，毒层约 +40%~70%，萤的小卡 +15%~30%）。
- 暗影骑士：血 1200→1000，护甲 4→3。
- 中毒不再要求同时燃烧才掉血（旧版 bug）。
- 城墙护盾最多叠到城墙上限的 1.2 倍（`TUNE.shieldCap`）：钧的工事、拒马原来靠无限叠盾硬扛第 9 夜首领。基础阵容第 9 夜 works 63%→25%、bulwark 75%→50%；第 7、8 夜基本不变，凑乘区的阵容不受影响（它们靠伤害赢）。
- 卡池重做（九夜版）：通用卡只留 7 张，其余分给人物或删掉；墨的冷热多了冰火瓶，冰爆瓶带减速；艾拉的军令改成被带动时更狠；连营、毒、雷的几张卡补了数值；穿甲 `pen` 对所有打法生效（原来只有飞斧类）。

系数集中在 `src/game/tuning.ts`，卡牌数值在 `src/data/cards.ts`。

## 怎么测

```bash
npm run bench                       # 各流派成型阵容逐夜打（tests/balance/builds.ts），每格 8 局
BUILD=mult RUNS=12 npm run bench    # mult：凑出乘区和连锁（回响、传说遗物、钻卡）
FULL=1 BUILD=mult npm run bench     # 完整游戏线：跑到第 15 夜（三颗宝石都拿，第 15 夜打隐藏首领）
TUNE='{"bossHp":2}' npm run bench   # 临时改系数试效果
ARCH=ice R=4 SEED=3 npx vitest run -c vitest.balance.config.ts tests/balance/why.balance.ts --reporter=verbose   # 单夜诊断（SEED 决定敌情；R 大于 9 时按完整线算，BOSS=mutebell 指定第 9 夜首领）
```

阵容是按「认真玩的玩家到第 N 夜大概有什么」手写的估计，用来看相对强弱和成长曲线，不等于真实胜率；前两夜只放了起手卡，偏难。
