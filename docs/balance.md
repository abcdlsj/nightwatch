# 平衡

## 伤害公式

```
伤害 = (基础 + 固定) × (1 + Σ加成%) × Π独立乘区 × 暴击 × 连锁倍率 × 目标易伤
```

- **加成%**（相加）：大部分遗物、天赋、2/4 层羁绊。前中期够用，后期收益被血量成长吃掉。
- **独立乘区**（各自相乘，修正项键名以 `x` 开头，界面显示成「×1.2」）：
  - 词缀「致命」×1.5
  - 钻品质 ×1.25
  - 6 层羁绊：刃 / 火 / 冰 / 电 ×1.3，毒 ×1.35
  - 传说遗物和玻璃大炮：守夜人之誓 ×1.2、深渊碎片 ×1.35、龙心（火）×1.3、千机匣（机）×1.25、淬毒之刃（刃）×1.3、残破的军旗 ×1.12、全城的灯谱 ×1.12、玻璃大炮 ×1.25
  - **C 位** ×1.25：每局一张主力，第 3、5、7 夜之前的跃迁事件（按人物不同）或「操练」事件来定；璃的星辉每层再 ×1.1
  - **站位**：占正中、在两端、两边都是辅助……（卡上标【站位】）
- **连锁倍率**：被回响、齐鸣、遗物带出来的出手，每深一层 +10%，最多 8 层（×1.8）。回响每张卡每秒最多被带动 2 次。

## 爽感机制（`src/sim/combo.ts`）

- **元素反应**：这一下的元素碰上敌人身上已有的状态。同一个敌人 0.5 秒内只反应一次（`TUNE.rxCd`），追加伤害按这一下实际打掉的血算，不再吃易伤和护甲。
  - 融化：火打冻住的 → +60%，解冻
  - 碎冰：非火暴击冻住的 → +80%，周围 40%，解冻
  - 超载：电打烧着的 → 周围 50% 并点着
  - 毒爆：火打中毒的 → 30% 范围伤害，毒传给周围（只拉平到源头的一半，不叠加）
  - 超导：电打减速或冻住的 → 易伤 20% 3 秒
- **流派连招**：同元素 3 秒内出手 4 次（至少两张卡）放一次大招，每个元素冷却 14 秒。伤害以窗口内最高的卡面伤害为基准：千刃 6 刀各 70%，燎原 30% 加灼烧，冰封 40% 加冻结 0.8 秒，雷暴 5 道各 60%，疫潮染毒，全速给【机】卡充能加速。
- **连杀分级**：连杀 10 / 25 / 50 / 100 时全队加速 0.6 / 1 / 1.5 / 2 秒。
- **联动**：两种元素各 2 张时额外生效一条（`SYN2`，15 组）；冷热、雷火、毒火、寒雷、寒锋各加强一种反应。

旋钮：`rx`、`rxCd`、`streakWin`、`streakN`、`streakCd`、`frenzy`、`syn2`（后两个填 0 可关掉，用来测各自贡献）。

## 怪物成长

- 普通敌人血量每夜 ×1.34，第 6 夜起每夜再 ×1.18（加入爽感机制后从 1.32 / 1.15 上调，让第 7、8 夜仍然要靠乘区）。
- 深渊之眼、深渊母巢血量 ×1.6。
- 选目标时精英和首领「往前算」12% 路程：不再躲在小怪后面一路走到墙下。

## 主要调整

- 闪电弹跳：第一跳 60%，之后每跳 ×0.8；弹跳次数叠得再多，总收益也有上限。
- 雷王杖：伤害 10→7，冷却 1.4→1.6，弹跳 6→4；学徒雷杖升级要 150 次弹跳（原 100）。
- 冰、毒、萤的卡整体加强（冰卡伤害约 +25%~50%，毒层约 +40%~70%，萤的小卡 +15%~30%）。
- 暗影骑士：血 1200→1000，护甲 4→3。
- 中毒不再要求同时燃烧才掉血（旧版 bug）。

系数集中在 `src/game/tuning.ts`，卡牌数值在 `src/data/cards.ts`。

## 怎么测

```bash
npm run bench                       # 各流派成型阵容逐夜打（tests/balance/builds.ts），每格 8 局
BUILD=mult RUNS=12 npm run bench    # mult：凑出乘区和连锁（回响、传说遗物、钻卡）
TUNE='{"bossHp":2}' npm run bench   # 临时改系数试效果
ARCH=ice R=4 npx vitest run -c vitest.balance.config.ts tests/balance/why.balance.ts --reporter=verbose   # 单夜诊断
```

阵容是按「认真玩的玩家到第 N 夜大概有什么」手写的估计，用来看相对强弱和成长曲线，不等于真实胜率；前两夜只放了起手卡，偏难。
