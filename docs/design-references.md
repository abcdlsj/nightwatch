# 设计参考

守夜人在设计上参考过的游戏，以及从每个游戏里拿了什么、为什么要改。这里只是设计笔记，游戏本身的介绍见 [README](../README.md)。

## 参考的游戏

| 游戏 | 参考了什么 | 在守夜人里是什么 |
|---|---|---|
| 大巴扎（The Bazaar） | 物品尺寸与相邻；物品是一条规则而不是一组数值 | 棋盘上的卡占 1–3 格，「相邻」「最左 / 最右」这类站位条件；卡牌的构筑钩子和词缀 |
| 杀戮尖塔（Slay the Spire） | 敌人意图、路线选择 | 敌情预告；夜晚编排与事件分支 |
| 吸血鬼幸存者（Vampire Survivors） | 自动战斗、满屏割草 | 战斗中不操作，卡牌自己出手打一波一波的怪 |
| 小丑牌（Balatro） | 表现与数字爆炸 | 连锁、暴击、跳字这类爽感表现（见 [balance.md](balance.md) 的「爽感机制」） |
| 土豆兄弟（Brotato） | 物品堆叠 | 同类卡越多越强的计数型效果 |

## 从大巴扎学到的构筑思路

2026-10-05 卡牌重做时整理。大巴扎的资料站在当时的开发环境里打不开，下面的总结来自搜索摘要和对游戏的了解，具体卡名和数值没有核对过。

1. **每件物品是一条规则，不是一组数值。** 数值只用来平衡。
2. **两条互相独立的标签轴。** 一条是类型，一条是效果。大量物品写成「每有一件 X 类」「当 X 类被使用时」，买什么类型就决定构筑方向。
3. **节奏是独立的一条轴。** 冷却、加速、充能、多重、弹药。同一件伤害物品放进不同的节奏引擎，玩起来完全不一样；物品互相触发的「无限流」也是一种构筑。
4. **成长和经济也是构筑。** 物品可以跨天永久成长，也有专门攒钱的物品。
5. **附魔改的是物品的轴，而不是加数值。** 同一个附魔落在不同物品上，效果按物品单独写。
6. **每个英雄只有几个核心机制，物品分成「引擎」和「收益」两类。**

### 不能照搬的部分

大巴扎是一对一对拼，冻结或减速对面的物品、拼治疗和护盾，在守夜人里没有对象。守夜人的对手是一波一波的怪，所以触发条件换成了战场事件，这是割草游戏独有的：

- 击杀触发：敌人死亡时爆炸，毒或火蔓延到旁边
- 溢出伤害：打死目标后多出来的伤害转给下一个敌人
- 敌人数量：场上敌人越多越强（清屏），或越少越强（首领杀手）
- 距离：敌人离城墙越近伤害越高，或专打远处
- 状态计数：每有一个被冻住或中毒的敌人就加点什么
- 涌潮和连杀：一波怪涌上来时、连杀到 N 时触发
- 城墙受击：墙挨打时反击或充能

护盾、护甲一类的防御效果因为有城墙机制，暂时不做。

### 落到守夜人的规则

- 每张卡至少有一个构筑钩子（「当……」「每有……」「永久」「若……」），纯数值的卡只留少数几张通用基础卡。
- 同一个流派里，两张卡的钩子不重复。
- 每张卡都有类型，每种类型有自己的天然机制：兵器（暴击、处决、单体成长）、火器（弹药、装填、多重）、药剂（状态叠层、引爆、传染）、机关（充能、加速、带动相邻）、灯具（数量）、天象（大范围、按敌人数量缩放）。
- 钩子有六种模板：触发型、计数型、成长型、节奏型、转化型、站位型。
