# 代号：连锁（Project Chain）

竖屏自动战斗构筑卡牌游戏原型。底层是可精算的伤害流水线，表层是满屏打怪的爽感。
参考：大巴扎（尺寸与相邻）、杀戮尖塔（意图与路线）、吸血鬼幸存者（自动战斗）、小丑牌（表现与数字爆炸）、土豆兄弟（物品堆叠）。

## 运行

```bash
./build.sh            # 拼接 src/ → dist/index.html，并做 JS 语法检查
open dist/index.html  # 直接用浏览器打开即可，无需服务器
```

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/01-shell.html` | 页面骨架、全部 CSS、DOM 结构 |
| `src/02-data.js` | 像素美术、卡牌、词缀、物品、事件、敌人、人物、天赋、剧情等纯数据 |
| `src/03-systems.js` | 背景着色器、音效、状态、卡牌/背包/备战事件/拖拽/弹层/剧情系统 |
| `src/04-battle.js` | 波次、战场渲染、触发与连锁、伤害结算、流程、存档、主循环 |
| `tools/smoke_test.py` | Playwright 冒烟测试：机器人自动打一整局 |
| `dist/index.html` | 构建产物（单文件，可直接发布） |

## 核心规则速览

- 8 格棋盘，卡牌分小/中/大（占 1/2/3 格），相邻才有协同。
- 伤害公式：`(基础 + 固定) × (1 + Σ百分比) × Π独立乘区 × 暴击`。
- 品质：铜 → 银 → 金 → 钻，两张同名同品质合成下一档；升级方向分“伤害型 / 冷却型 / 混合型”。
- 每夜之间 3 站随机事件（商店、宝箱、祭坛、附魔、训练……），8 夜后决战深渊之眼。

## 开发约定

- 每个改动独立提交，提交信息用 `类型(范围): 说明`，如 `feat(enemy): 新增自爆鼠`。
- 提交前运行 `./build.sh`，大改动再跑 `python3 tools/smoke_test.py 0`。
- `dist/index.html` 随源码一起提交，保证任何一个提交都能直接打开试玩。
