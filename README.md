# 代号：连锁（Project Chain）

竖屏自动战斗构筑卡牌游戏。底层是可精算的伤害流水线，表层是满屏打怪的爽感。
参考：大巴扎（尺寸与相邻）、杀戮尖塔（意图与路线）、吸血鬼幸存者（自动战斗）、小丑牌（表现与数字爆炸）、土豆兄弟（物品堆叠）。

## 运行

```bash
./build.sh            # 拼接 src/ → dist/index.html，并做 JS 语法检查
open dist/index.html  # 直接打开能玩；要看到自带字体，用 python3 -m http.server -d dist 起个服务
```

## 核心规则速览

- 8 格棋盘，卡牌分小/中/大（占 1/2/3 格），相邻才有协同。
- 伤害公式：`(基础 + 固定) × (1 + Σ百分比) × Π独立乘区 × 暴击`。
- 品质：铜 → 银 → 金 → 钻，两张同名同品质合成下一档；升级方向分“伤害型 / 冷却型 / 混合型”。
- 每夜之前 3 站随机事件（商店、宝箱、祭坛、附魔、训练……），8 夜后决战深渊之眼。
- 天赋是随机池：第 1/3/5/7 夜之前固定有一次夜谈，回答决定倾向，再三选一；备战时偶尔碰到「过路人」「残破的手札」也能学。
- 每局随机一套敌人：「亡者与深渊」或「霜潮」。两套按角色一一对应，首领共用；霜潮的大家伙撞墙会冻住一张卡。
- 拖卡到被占的格子会把两边的卡挤开（插入排列），挤不下才算放不下。
- 标签两套：元素（刃火冰电机毒）和功能（兵器、火器、药剂、机关、灯具、天象），「每有一张某类卡」按这两套计数。
- 羁绊：棋盘上同元素的卡凑到 2 / 4 / 6 张，全队拿加成，层数叠加；备战预览里点「羁绊」看详情。
- 加码：走完三站后可以给今晚加一条难度（蜂拥、铁皮、急行军、危墙、熄灯），守住拿金币、遗物或升档。最后一夜没有加码。
- 连杀：1 秒内接着杀就续上，每 25 连杀掉 1 金；精英和首领倒下时有短暂慢镜头。
- 夜谈可以选「不学」，拿 3 金走人。
- 起手：选完人以后从三套起手里挑一套（每人四套，随机给三套，第一套是老规矩）。
- 锁卡：商店里点卡右上角的「留」，这张卡会原价出现在下一家店，直到买下或者解锁。一次只锁一张。
- 拦路：第 2 夜起备战偶尔出现（第 4、8 夜没有）。打一场精英带小怪的仗，墙只吃一半伤害。打完拿金币；精英撞墙之前打倒它，再从三件好遗物里挑一件。墙快塌了就算输，墙最少留 1，这局不算输。精英三种：屠夫、山岩巨像、白骨主教（霜潮里是霜狼王、老雪人、冰棺主祭）。
- 霜潮专属：冰鸦（过半场俯冲）、冰壳蟹（前 3 下打在壳上，灼烧中毒不吃壳）、冰晶法师（停在远处每 5 秒冻一张卡）。
- 出怪：怪从北边出来，走过一小段才进射程（虚线）。游魂有一半时候直接在半路的雾里冒出来（霜潮是雪雾），宝箱怪一开始就躺在半路上。
- 第八夜的首领开局随机：深渊之眼，或者深渊母巢（产卵、酸雾清掉一半充能、蜕壳上盾）。
- 无尽长夜：守到黎明后可以「接着守下去」。血量接着涨，单数夜带一个精英，每四夜一个首领（首领血量每夜 ×1.4）。只记最多撑了几夜，不再给熟练。
- 对路：手里有兵器、成长卡、弹药卡、大型卡或某个元素的卡时，遗物祭坛 / 包裹 / 熔炉 / 杂货铺 / 夜谈 / 过路人有 40% 左右的几率多出一个「对路」选项（补范围、攻速、扩散）。这些遗物和天赋平时不进随机池。
- 熟练：每个守夜人各自记，守住一夜 +1、守到黎明再 +2。5 / 15 / 30 / 50 点分别解锁：开局多 2 金、夜谈多一个候选、开局送一件普通遗物、开局第一张铜卡升银。
- 长夜：在当前最高难度守到黎明一次，解锁下一档（共 8 档，逐档叠加），开局选人时调。
- 图鉴：标题页「图鉴」分卡牌 / 遗物 / 天赋 / 敌人四页。卡牌都能翻，没拿到过的灰着，卡面显示拿到过的最高品质；遗物、天赋、敌人没碰到过的是问号。敌人详情里有血量、撞墙、招式、见过几局、打倒几个。
- 过往守夜：标题页和结算页都能进。每局一条：人物、结果、敌人套、难度、最后的棋盘、遗物、天赋、这局的成就；守到黎明后接着守的算同一局。
- 成就 31 个，标题页可看；进度和长夜解锁不跟单局存档走，删档不丢。

## 触发框架

卡牌和物品在数据里声明 `on:{事件:(卡, 上下文)=>{}}`，战斗引擎在对应时机 `emit(事件)`：

| 事件 | 时机 |
| --- | --- |
| `start` | 开战 |
| `use` | 任意卡触发 |
| `hit` / `crit` | 命中 / 暴击 |
| `burn` / `poison` / `freeze` | 施加灼烧 / 中毒 / 冻结 |
| `bounce` | 闪电弹跳 |
| `kill` | 击杀（带 `burning`、`poisoned`、`frozen`、`elite`） |
| `wall` | 城墙受击 |
| `charge` | 某张卡被充能 |
| `chain` | 连锁数到 5 的倍数 |

每张卡每种事件每秒最多响应 8 次，防止互相触发成死循环。卡牌还可以用 `onWin` 在守住一夜后结算成长。

关键词：冻结、加速、弹药、装填、多重、易伤、处决、成长、任务。说明文字写在 `KW` 里，卡牌描述里出现【关键词】时详情页会自动附上解释。`passive:1` 表示没有冷却、只靠事件充能。

## 开发约定

- 每个改动独立提交，提交信息用 `类型(范围): 说明`，如 `feat(enemy): 新增自爆鼠`。
- 提交前运行 `./build.sh`，大改动再跑 `python3 tools/smoke_test.py 0`。
- `dist/` 是构建产物，不入库；拉下代码后运行 `./build.sh` 生成。

## 叙事原则

- 剧情发生在战斗里：夜晚剧情按时间节拍以字幕/气泡出现，首领按意图和血量说话。
- 文戏只做表现层：台词系统不读写任何战斗数值、不暂停模拟、不接收点击。
- 世界观线索分散在三处：战斗台词（主线）、天赋台词（人物）、卡牌传闻（世界）。
