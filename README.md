# 守夜人（Night Watch）

竖屏自动战斗构筑卡牌游戏。底层是可精算的伤害流水线，表层是满屏打怪的爽感。
参考：大巴扎（尺寸与相邻）、杀戮尖塔（意图与路线）、吸血鬼幸存者（自动战斗）、小丑牌（表现与数字爆炸）、土豆兄弟（物品堆叠）。

技术栈：TypeScript + Vite，界面用原生 DOM，战场用 Canvas 2D（低分辨率像素画布放大显示），音乐音效全部 WebAudio 现场合成。
同一份构建产物可以发布成网页（Vercel），也可以装进 Capacitor 原生壳上架 iOS / Android；以后接 Steam 时再加一层桌面壳。

## 运行

需要 Node 20.19 以上。

```bash
npm install
npm run dev        # 开发服务器，改代码自动刷新
npm run build      # 构建到 dist/（Vercel 用的就是这个）
npm run preview    # 本地预览构建结果（端口 4317）
npm run check      # 类型检查 + 单元测试 + 构建，提交前跑
npm run e2e        # 冒烟测试：机器人自动打一局（需要先 build；首次要 npx playwright install chromium）
```

网址加 `?seed=数字` 可以固定种子，同一种子、同样的操作，出怪、商店、掉落和战斗结果都一样，方便复现问题。

## 装到主屏（网页版）

网页版是 PWA：iPhone 用 Safari 打开，点「分享 → 添加到主屏幕」；安卓 Chrome 会自己提示安装。从主屏打开时全屏、没有浏览器栏，断网也能玩。

- `public/manifest.webmanifest`：名字、竖屏、图标（`public/icons/`，由 `node tools/make-app-assets.mjs` 生成）。
- `public/sw.js`：离线缓存。页面先走网络，带哈希的资源直接用缓存；每次构建换一个缓存版本（`__BUILD_ID__`）。只在正式构建的网页版注册，原生壳和开发服务器不注册。
- 从主屏打开时 `<html>` 带 `standalone` 类；iOS Safari 里没装的话，标题页会提示一次怎么装（`src/platform/pwa.ts`）。

## 手机（iOS / Android）

原生壳用 Capacitor，工程在 `ios/` 和 `android/`，配置在 `capacitor.config.ts`（appId `com.abcdlsj.nightwatch`，上架前定下来就不能再改）。

```bash
npm run build && npx cap sync     # 把 dist/ 同步进原生工程
npx cap open ios                  # Xcode 打开，选设备运行 / Archive 上架
npx cap open android              # Android Studio 打开（需要装 Android SDK）
```

- 只支持竖屏；刘海和圆角靠 CSS 的 safe-area-inset 处理。
- 原生壳里存档写进系统存储（`@capacitor/preferences`），第一次启动会把 WebView 里的旧数据搬过去；震动用系统震感；切后台自动静音；Android 返回键先关弹层和背包。这些都在 `src/platform/native.ts`，网页版不加载。
- 应用名：对外统一叫 Night Watch（网页标题、主屏、iOS / Android 显示名），游戏里的中文名是「守夜人」。
- 图标和启动图：`node tools/make-app-assets.mjs` 生成 `resources/` 源图和网页图标 `public/icons/`（一幅 32×32 像素画：远处的月、近处的地、暗红的城墙、墙头提灯的人），再 `npx @capacitor/assets generate --ios --android --assetPath resources` 导出原生各尺寸（别漏 `--ios --android`，不然它会改写 manifest）。

## 分层

规则层和模拟层不碰 DOM，换渲染方式、换平台时只动上层。`tests/unit/layers.test.ts` 会检查：

| 层 | 可以依赖 |
| --- | --- |
| `core` | 无 |
| `data` | `core` |
| `i18n` / `locales` | `data`、`core` |
| `game` | 上面这些 + `platform` |
| `sim` | 上面这些 + `game` |
| `render` / `audio` / `ui` / `app` | 全部 |

战斗模拟对外只通过 `sim/view.ts` 的 `SimView` 接口「喊一声」（粒子、飘字、音效、台词、卡牌闪烁……），界面层在 `ui/battle-view.ts` 实现它；无界面跑模拟时用空实现。

随机数分两种：规则相关的（出怪、商店、掉落、暴击……）走 `core/rng.ts` 的 `rng`，可复现；纯表现的（粒子、飘字、台词挑哪句）用 `vr()`，不影响结算。存档里记着进入备战前的随机数状态，读档后当晚的出怪和三站跟存档时一样。

## 多语言

- 屏幕上的字全部在 `src/locales/zh-CN/`：`cards` `relics` `talents` `enemies` `events` `heroes` 是内容文案，`story` 是剧情和台词，`terms` 是术语（元素、品质、词缀……），`meta` 是成就、难度、加码等，`ui` 是界面文字。
- 数据表（`src/data`）只放机制，不放文字；启动时 `i18n/apply.ts` 把文案填进去，代码里照常读 `ITEMS[k].n`。
- 界面文字用 `t('prep.refresh', { n: 2 })`，参数写成 `{n}`。
- 加一门语言：复制 `locales/zh-CN` 改译文，在 `i18n/index.ts` 的 `PACKS` 里登记，再给字体子集补字。`tests/unit/i18n.test.ts` 会检查缺键。

## 核心规则速览

- 8 格棋盘，卡牌分小/中/大（占 1/2/3 格），相邻才有协同。
- 伤害公式：`(基础 + 固定) × (1 + Σ加成) × Π独立乘区 × 暴击 × 连锁倍率 × 易伤`。后期主要靠独立乘区（致命、钻品质、6 层羁绊、传说遗物）和连锁，详见 docs/balance.md。
- 品质：铜 → 银 → 金 → 钻，两张同名同品质合成下一档；升级方向分“伤害型 / 冷却型 / 混合型”。
- 每夜之前 3 站随机事件（商店、宝箱、祭坛、附魔、训练、难民、血祭、换防……），第 4 夜暗影骑士，第 8 夜一个精英压阵，第 9 夜决战首领。
- 跃迁事件：第 3、5、7 夜之前多一站，每个人物不同（艾拉点将、墨课题、萤图纸、钧布防图、璃星象），用来定 C 位和流派方向。
- C 位：每局一张主力，独立乘区 ×1.25；「为 C 位充能 / 增伤」的辅助卡围着它转。
- 【站位】：部分卡按格子算加成——占正中、在两端、两边都是辅助、相邻同类卡越多越强。
- 普朗克时间 250ms：同一张卡两次触发至少隔 0.25 秒（每秒最多 4 次），冷却、回响、齐鸣都算。
- 夜谈的回答当场给东西：攻 → 一张卡，守 → 城墙上限，术 → 遗物，财 → 金币；同时决定接下来更容易抽到哪类天赋。
- 天赋是随机池：第 1/3/5/7 夜之前固定有一次夜谈，回答决定倾向，再三选一；备战时偶尔碰到「过路人」「残破的手札」也能学。
- 每局随机一套敌人：「亡者与深渊」或「霜潮」。两套按角色一一对应，首领共用；霜潮的大家伙撞墙会冻住一张卡。
- 拖卡到被占的格子会把两边的卡挤开（插入排列），挤不下才算放不下。
- 标签两套：元素（刃火冰电机毒）和功能（兵器、火器、药剂、机关、灯具、天象），「每有一张某类卡」按这两套计数。
- 羁绊：棋盘上同元素的卡凑到 2 / 4 / 6 张，全队拿加成，层数叠加；备战预览里点「羁绊」看详情。
- 加码：走完三站后可以给今晚加一条难度（蜂拥、铁皮、急行军、危墙、熄灯），守住拿金币、遗物或升档。最后一夜没有加码。
- 连杀：1 秒内接着杀就续上，每 25 连杀掉 1 金；精英和首领倒下时有短暂慢镜头。
- 夜谈可以选「不学」，拿 3 金走人。
- 起手：选完人以后从三套起手里挑一套（每人四套，随机给三套，第一套是老规矩）。
- 锁卡：商店里点卡右上角的「留」，这张卡会原价出现在下一家店，直到买下或者解锁。一次只锁一张。
- 拦路：第 2 夜起备战偶尔出现（第 4 夜和最后一夜没有）。打一场精英带小怪的仗，墙只吃一半伤害。打完拿金币；精英撞墙之前打倒它，再从三件好遗物里挑一件。墙快塌了就算输，墙最少留 1，这局不算输。精英三种：屠夫、山岩巨像、白骨主教（霜潮里是霜狼王、老雪人、冰棺主祭）。
- 霜潮专属：冰鸦（过半场俯冲）、冰壳蟹（前 3 下打在壳上，灼烧中毒不吃壳）、冰晶法师（停在远处每 5 秒冻一张卡）。
- 出怪：怪从北边出来，走过一小段才进射程（虚线）。游魂有一半时候直接在半路的雾里冒出来（霜潮是雪雾），宝箱怪一开始就躺在半路上。
- 第九夜的首领五个轮换（每个人物没打过的先来，五个都打过一轮再重来）：
  - 深渊之眼：召蝙蝠、凝视冻住两张卡、硬化。
  - 深渊母巢：产卵、酸雾清掉一半充能、蜕壳上盾。
  - 哑钟：丧钟让最近倒下的敌人变成游魂站起来、噤声 4 秒内卡牌不再互相带动、余音给全场敌人上盾。
  - 雾母：雾幕把射程线往城墙压、引魂让小怪冲锋、摸金偷钱（打倒她连本带利还回来）。
  - 攻城王：放兵、齐射往城墙砸石头、撞城突然加速。
  - 招式在 `src/sim/enemies.ts` 的 `INTENTS` 表里，首领数据只是从表里挑招式组合（带参数）。
- 完整游戏线（15 夜）：某个人物用三个流派的起手各守到一次黎明（完整线里打过第 9 夜也算）后，起手页顶上出现「完整游戏线」勾选框。
  - 第 9 夜首领倒下，天不亮；第 12 夜再来一个首领（和第 9 夜不同），第 14 夜两个精英压阵。
  - 第 6、10、13 夜之前各有一段宝石剧情（红·余烬、蓝·星泪、绿·新芽），可以拿也可以不拿。拿了是一件带代价的传说遗物（伤害 ×1.12 但城墙 -6 / 开战充能和弹跳 +1 但店里贵 1 金 / 每夜回墙和开战护盾但敌人快 5%）；不拿换金币、遗物或城墙，剧情走另一支，这颗以后不会再有。
  - 三颗都拿了，第 15 夜是这个人物自己的隐藏首领：初誓者（艾拉）、灰袍（墨）、熄灯人（萤）、黑墙（钧）、失星（璃）；少一颗，第 15 夜只有一段对话，然后天亮（结局标题是「黎明，还缺一块」）。
  - 编排在 `src/game/plan.ts`，剧情取用在 `src/game/story.ts`（人物自己的优先，公共的兜底）。
- 无尽长夜：守到黎明后可以「接着守下去」。血量接着涨，单数夜带一个精英，每四夜一个首领（第 9 夜以后普通敌人每夜 ×1.24，首领每夜 ×1.3）。只记最多撑了几夜，不再给熟练。
- 对路：手里有兵器、成长卡、弹药卡、大型卡或某个元素的卡时，遗物祭坛 / 包裹 / 熔炉 / 杂货铺 / 夜谈 / 过路人有 40% 左右的几率多出一个「对路」选项（补范围、攻速、扩散）。这些遗物和天赋平时不进随机池。
- 人物解锁：初始只有艾拉；用一个人物守到黎明一次，解锁下一个（艾拉 → 墨 → 萤 → 钧 → 璃）。
- 熟练：每个守夜人各自记，守住一夜 +1、守到黎明再 +2。5 / 15 / 30 / 50 点分别解锁：开局多 2 金、夜谈多一个候选、开局送一件普通遗物、开局第一张铜卡升银。专属卡分三个流派，第二、三个流派在熟练 1 / 2 级解锁（没解锁的不进店）。
- 长夜：每个人物各自解锁，在当前最高难度守到黎明一次解锁下一档（共 8 档，逐档叠加），在起手页调。
- 设置：音乐、音效、震动、震屏、伤害数字、新手提示、清除进度（顶栏右上角 ⚙）。
- 图鉴：标题页「图鉴」分卡牌 / 遗物 / 天赋 / 敌人四页。卡牌都能翻，没拿到过的灰着，卡面显示拿到过的最高品质；遗物、天赋、敌人没碰到过的是问号。敌人详情里有血量、撞墙、招式、见过几局、打倒几个。
- 过往守夜：标题页和结算页都能进。每局一条：人物、结果、敌人套、难度、最后的棋盘、遗物、天赋、这局的成就；守到黎明后接着守的算同一局。
- 成就 31 个，标题页可看；进度和长夜解锁不跟单局存档走，删档不丢。

## 触发框架

卡牌、遗物、天赋的触发型效果写在 `src/sim/hooks.ts`，按 id 登记；战斗引擎在对应时机 `emit(事件)`：

| 事件 | 时机 |
| --- | --- |
| `start` | 开战 |
| `use` | 任意卡触发 |
| `hit` / `crit` | 命中 / 暴击 |
| `burn` / `poison` / `freeze` | 施加灼烧 / 中毒 / 冻结 |
| `bounce` | 闪电弹跳 |
| `kill` | 击杀（带 `burning`、`poisoned`、`frozen`、`elite`） |
| `wall` | 城墙受击 |
| `charge` | 某张卡被充能 |
| `chain` | 连锁数到 5 的倍数 |

每张卡每种事件每秒最多响应 8 次，防止互相触发成死循环。卡牌还可以用 `onWin` 在守住一夜后结算成长。

关键词：冻结、加速、弹药、装填、多重、易伤、处决、成长、任务。说明写在 `locales/zh-CN/terms.ts` 的 `kw` 里，卡牌描述里出现【关键词】时详情页会自动附上解释。`passive:1` 表示没有冷却、只靠事件充能。

## 开发约定

- 每个改动独立提交，提交信息用 `类型(范围): 说明`，如 `feat(enemy): 新增自爆鼠`。
- 提交前运行 `npm run check`，大改动再跑 `npm run e2e`。
- 新增文字只写进 `src/locales`；出现新汉字时 `npm run build` 会提醒跑 `npm run fonts`。
- `dist/` 是构建产物，不入库。

## 叙事原则

- 剧情发生在战斗里：夜晚剧情按时间节拍以字幕/气泡出现，首领按意图和血量说话。
- 文戏只做表现层：台词系统不读写任何战斗数值、不暂停模拟、不接收点击。
- 世界观线索分散在三处：战斗台词（主线）、天赋台词（人物）、卡牌传闻（世界）。

## 美术流程

卡牌图标、人物立绘、首领大图都写成 `tools/pixelgen.py` 里的绘制函数，改完运行：

```bash
npm run art                              # 重新生成 src/data/art/generated.ts
python3 tools/pixelgen.py --preview      # 另外输出 shots/ 下的预览图（需要 Pillow）
```
