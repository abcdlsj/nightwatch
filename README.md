# 代号：连锁（Project Chain）

竖屏自动战斗构筑卡牌游戏原型。底层是可精算的伤害流水线，表层是满屏打怪的爽感。
参考：大巴扎（尺寸与相邻）、杀戮尖塔（意图与路线）、吸血鬼幸存者（自动战斗）、小丑牌（表现与数字爆炸）、土豆兄弟（物品堆叠）。

## 运行

```bash
./build.sh            # 拼接 src/ → dist/index.html，并做 JS 语法检查
open dist/index.html  # 直接用浏览器打开即可，无需服务器
```

## 核心规则速览

- 8 格棋盘，卡牌分小/中/大（占 1/2/3 格），相邻才有协同。
- 伤害公式：`(基础 + 固定) × (1 + Σ百分比) × Π独立乘区 × 暴击`。
- 品质：铜 → 银 → 金 → 钻，两张同名同品质合成下一档；升级方向分“伤害型 / 冷却型 / 混合型”。
- 每夜之前 3 站随机事件（商店、宝箱、祭坛、附魔、训练……），8 夜后决战深渊之眼。
- 天赋是随机池：第 1/3/5/7 夜之前固定有一次夜谈，回答决定倾向，再三选一；备战时偶尔碰到「过路人」「残破的手札」也能学。
- 每局随机一套敌人：「亡者与深渊」或「霜潮」。两套按角色一一对应，首领共用；霜潮的大家伙撞墙会冻住一张卡。
- 拖卡到被占的格子会把两边的卡挤开（插入排列），挤不下才算放不下。
- 标签两套：元素（刃火冰电机毒）和功能（兵器、火器、药剂、机关、灯具、天象），「每有一张某类卡」按这两套计数。

## 触发框架

卡牌和物品在数据里声明 `on:{事件:(卡, 上下文)=>{}}`，战斗引擎在对应时机 `emit(事件)`：

| 事件 | 时机 |
| --- | --- |
| `start` | 开战 |
| `use` | 任意卡触发 |
| `hit` / `crit` | 命中 / 暴击 |
| `burn` / `poison` / `freeze` | 施加灼烧 / 中毒 / 冻结 |
| `bounce` | 闪电弹跳 |
| `kill` | 击杀（带 `burning`、`poisoned`、`frozen`、`elite`） |
| `wall` | 城墙受击 |
| `charge` | 某张卡被充能 |
| `chain` | 连锁数到 5 的倍数 |

每张卡每种事件每秒最多响应 8 次，防止互相触发成死循环。卡牌还可以用 `onWin` 在守住一夜后结算成长。

关键词：冻结、加速、弹药、装填、多重、易伤、处决、成长、任务。说明文字写在 `KW` 里，卡牌描述里出现【关键词】时详情页会自动附上解释。`passive:1` 表示没有冷却、只靠事件充能。

## 开发约定

- 每个改动独立提交，提交信息用 `类型(范围): 说明`，如 `feat(enemy): 新增自爆鼠`。
- 提交前运行 `./build.sh`，大改动再跑 `python3 tools/smoke_test.py 0`。
- `dist/` 是构建产物，不入库；拉下代码后运行 `./build.sh` 生成。

## 叙事原则

- 剧情发生在战斗里：夜晚剧情按时间节拍以字幕/气泡出现，首领按意图和血量说话。
- 文戏只做表现层：台词系统不读写任何战斗数值、不暂停模拟、不接收点击。
- 世界观线索分散在三处：战斗台词（主线）、天赋台词（人物）、卡牌传闻（世界）。

